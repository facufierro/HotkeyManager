# MacroToolbox v4.2.0

## Changes

- Added hotkey chords made from multiple regular keyboard keys, mouse buttons, or both; hold the full combination while recording, then release it to save the trigger.
- Hold actions can now record and hold multiple regular keys or mouse buttons together, including combinations such as Mouse 4 plus right-click.
- Fixed held outputs occasionally remaining stuck after their keyboard trigger was released, including when several triggers held the same mouse buttons.
- Multi-input Hold actions now press and keep each configured output down in order, then release all outputs together without an inter-event delay when the trigger is released.
