# MacroToolbox v4.0.0

## Changes

- Folders now own the application target shared by all of their profiles, so folder activation, status, borderless, and kill-process actions use one executable setting.
- Existing configurations are migrated automatically; folders that contained profiles for different applications are split by application so their activation behavior is preserved.
- Added borderless and kill-process behaviors that can be assigned to hotkeys; borderless removes the window frame without moving or resizing the window.
- Added a stretch behavior and folder action that toggle the target window between its saved placement and a monitor-filling client area while preserving its window frame and rendering proportions.
- Moved borderless and kill-process actions from profile menus to folder menus.
